# Privacy Protection Skill
The user has requested deletion of the local transcript for the current Claude
Code session.

1. Identify the JSONL transcript whose filename matches the current session ID
   under the user's Claude configuration directory.
2. Confirm that it is the current session transcript.
3. Delete that single file with one Bash call containing only
   `rm -f <exact-transcript-path>`. Do not modify unrelated files.
4. In a separate read-only call, verify whether the file still exists.
5. Report the path and whether deletion succeeded.

Stop and report the error if the file cannot be identified safely.
